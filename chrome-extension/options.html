Django DevBar Settings

Configuration for the django-devbar Chrome extension.

Custom Domains

By default the extension works on localhost, 127.0.0.1, *.local, and *.test. Add any extra domains (e.g. a staging server) where DevBar headers should also be read.

⚠️ Chrome will ask for permission to access each new domain so the extension can inject the show/hide toggle into those pages. You can deny the permission — the DevTools panel metrics will still work, but the on-page toggle button will not.
